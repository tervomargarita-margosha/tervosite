## Решения Марго (18.11)
| Вопрос | Решение |
|---|---|
| Палитра | Тёмно-синий, кремовый, бронза. Олива снята |
| Основной текст | Inter 300 |
| Порядок главной | 1 первый экран → 2 «Обратиться за помощью – важный, но часто сложный шаг» → 3 видео-визитка → дальше как в структуре |
| Первый экран | Без строки «от 15 лет, до 18 – с согласия родителей». Фото Марго без фона: на компьютере почти во всю высоту блока, между текстом и правым краем; на телефоне в круге («выглядывает» из круга). Ссылка «Как начинается работа» ведёт к блоку «Начало работы» |
| Видео | Вертикальное, рамка 9:16 не во весь экран (на телефоне около 2/3 ширины), вокруг кольца. Без заголовка, подпись сверху: «о работе со мной в двух словах» |
| С чем я не работаю | «наркотические и алкогольные зависимости в активной фазе употребления»; строки ровными колонками; без пункта «к кому обратиться» |
| Квалификация | Без «100 часов консультаций» и без подписи про миниатюры. «Если вам так же важно знать что-то обо мне как о человеке, можете заглянуть на отдельную страницу» (Марго доработает фразу) |
| Я работаю не одна | Стрелки к «Я» разведены; кольцо вокруг «Я» тонкое. На телефоне пять опор в кругах полукругом над маленьким «Я», от каждой стрелка к «Я». Текст из последней версии карточки |
| На сессиях я (телефон) | Пары разнесены по экрану: «не делаю» выше и левее → стрелка → «делаю» ниже и правее |
| Начало работы | Шаги раскрываются по нажатию (как частые вопросы). Слева коллаж «начало работы» (только здесь). «Запись утверждается по стопроцентной предоплате» – без уточнения, что за каждую сессию |
| Условия | Только кабинет и карта; на телефоне – меньше и рядом |
| Запись | Без фото |
| Подвал | Без строки «психолог не врач и не ставит диагнозов» |
| Блок статей | «Информация и инструменты для самопомощи» |
| Типографика | Короткое тире «–» вместо длинного. Без висячих строк и переносов внутри слов; «гештальт-подход», «гештальт-терапия», «55 минут», диапазоны цифр не разрываются; предлоги и союзы привязаны к следующему слову |
| Высота блоков | Внизу блоков не должно быть лишней пустоты – воздух как в остальных блоках |

## Новые формулировки (черновые, пройдут редактуру)
«Пара минут, чтобы услышать мой голос и увидеть, как я говорю о работе» (видео, компьютер), подписи «о работе со мной в двух словах», «полезное», «частые вопросы», «Здесь можно спокойно понять, подхожу ли я вам…».
