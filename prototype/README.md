# Прототип сайта tervopsy.ru

HTML-прототип всех страниц сайта психолога Маргариты Терво. Обычные файлы: HTML, CSS, немного JS, свои шрифты и картинки. Без сторонних сервисов, форм, счётчиков и cookie.

Прототип закрыт от поисковиков: на каждой странице стоит `noindex, nofollow`, в `robots.txt` – `Disallow: /`.

## Как посмотреть у себя

Из папки репозитория:

```bash
cd prototype
python3 -m http.server 8080
```

Откройте в браузере http://localhost:8080. Остановить сервер – `Ctrl+C`.

Страницу 404 этот простой сервер не показывает: её можно открыть напрямую по адресу http://localhost:8080/404.html. На GitHub Pages она работает сама.

## Как опубликовать на GitHub Pages (делает Марго)

1. Войдите в GitHub сами и откройте репозиторий.
2. **Settings → Pages → Build and deployment → Source:** выберите **GitHub Actions**.
3. **Actions → «Опубликовать прототип» → Run workflow.** Через 1–2 минуты появится ссылка вида `https://<ваш-ник>.github.io/<репозиторий>/`.
4. После правок публикуйте снова тем же способом. Сам по себе прототип не публикуется.

⚠️ Страницу на GitHub Pages может открыть любой, у кого есть ссылка. Поиск её не покажет (noindex), но ссылку лучше никому не отправлять: в прототипе заглушки и чужие картинки, которые до запуска нужно заменить.

## Как править

- **Текст страницы** – прямо в её HTML. Потом запустите типограф (из корня репозитория):
  ```bash
  python3 scripts/typograph.py
  ```
  Он расставит неразрывные пробелы, заменит «—» на «–» и запретит переносы в «гештальт-подход», «11:00–20:00» и т. п. Запускать можно сколько угодно раз.
- **Шапка, подвал, общие строки в `<head>`** – в `scripts/partials/`, затем:
  ```bash
  python3 scripts/sync-partials.py && python3 scripts/typograph.py
  ```
- **Новые картинки** – положите в `design/mockups/assets/`, добавьте ширины в `scripts/optimize-images.py` и запустите его (нужен Pillow).
- Все ссылки относительные, поэтому сайт работает и в подпапке GitHub Pages, и на своём домене.
