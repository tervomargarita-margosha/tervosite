# tervopsy.ru – материалы для переноса в Claude Code

Выгрузка из проекта «Маркетинг психолога» (claude.ai) на 18.11.2026. Сайт частного психолога Маргариты Терво (гештальт-подход, СПб и онлайн).

**Статус:** структура и дизайн главной утверждены Марго. HTML-прототип всех страниц с заглушками собран в `prototype/` (18.11.2026), ждёт просмотра Марго.

## Как начать
1. Распакуй архив в папку будущего репозитория (например, `~/projects/tervopsy-site`).
2. Открой её в Claude Code.
3. Вставь промпт из `START-PROMPT.md`.

## Чего в архиве нет
- Файлов карточек Авито и сканов документов (диплом, сертификаты) – они на холсте «Карточки Авито» и у Марго на компьютере.
- Таблицы «Учёт заявок» – Марго присылает выгрузку без персональных данных.
- Доступов и паролей – входы Марго делает сама.
