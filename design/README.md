# Дизайн сайта tervopsy.ru

Утверждено Марго 18.11.2026 (три круга правок). Подробности решений – `docs/04-sayt-dizayn-shag-2.md`.

## Что здесь
| Папка / файл | Что это |
|---|---|
| `mockups/home-mobile.html` | Главная целиком, телефон 390 px. Открывается в браузере, картинки из `mockups/assets/` |
| `mockups/home-desktop.html` | Главная целиком, компьютер 1440 px |
| `mockups/style-board.html` | Основа стиля: палитра, шрифты, элементы, атмосферные картинки |
| `mockups/assets/` | Обработанные картинки (вырезанный фон, обрезка) – их и брать в прототип |
| `tokens.json` | Дизайн-токены: цвета, шрифты, размеры, радиусы, тени, отступы |
| `canvas-source/` | Исходники холста Claude Design (`*.dc.html` + `canvas.json`). Картинки там по адресам `/_blob/…` холста – вне холста не грузятся, файлы нужны только как справка по разметке |
| `generator/` | Python-скрипт, которым собирались макеты (`gen.py` – артборды холста, `export.py` – самостоятельные HTML). Справка, не код сайта |

**Макеты – статичные эталоны внешнего вида, а не код сайта.** В них фиксированная ширина (390 и 1440) и инлайн-стили. Прототип верстается заново: семантично, адаптивно (mobile-first), на CSS-переменных из `tokens.json`.

## Визуальный язык (коротко)
- Глубокий тёмно-синий + тёплый кремовый + бронзовые линии. Элегантно, спокойно, «бумажно», с воздухом. Без белого с пастелью.
- **Круги, а не арки.** Фото, номера шагов, иконки, «Я» в схеме – в кругах с тонким бронзовым кольцом.
- **Плашки без обводок**: только мягкая тень; радиус 28 px, таблетки 999 px.
- Подпись-кикер курсивом (Cormorant 600 italic, бронза) над каждым заголовком h2.
- Пунктирные стрелки из точек с треугольным наконечником; зазор между стрелкой и элементом.
- Разделитель: две тонкие бронзовые линии с ромбом.
- Диагональ с бронзовой линией под первым экраном.
- Бумажная фактура на кремовых фонах; на тёмных фонах – мягкое «окно света» (радиальный градиент).
- Иконки – тонкие линейные SVG (stroke 1.5), без эмодзи.
- Ритм фонов главной: тёмный первый экран → кремовый → кремовый глубже → … тёмные «опорные» блоки («Я работаю не одна», «На сессиях я», «Запись») → тёмный подвал.

## Типографика – правила Марго
- Короткое тире «–» вместо длинного.
- Без висячих строк: неразрывный пробел после предлогов/союзов (в, и, с, на, не, по, для, к, о, у, а, от, до, из, за, или, но, что, как, я, вы…), частицы «бы/ли/же» привязаны к предыдущему слову, последнее слово абзаца не остаётся одно.
- Не переносить слова через дефис («гештальт-подход», «гештальт-терапия»), «55 минут», «1000 ₽», «11:00–20:00» – `white-space: nowrap` или неразрывные пробелы.
- `text-wrap: balance` для заголовков, `text-wrap: pretty` для абзацев.
- Логика обработки – функции `nb()`, `_textnode()`, `typo()` в `generator/gen.py`; в прототипе стоит сделать то же (скрипт сборки или аккуратная ручная расстановка `&nbsp;`).
